03Frequently asked

Connection & pairing

My iPhone can't find my Mac
  1. Make sure Macropad Helper is running — look for its icon in the Mac menu bar.
  2. Check both devices are on the same network. Guest networks and some office/hotel Wi-Fi block devices from seeing each other.
  3. On iPhone, go to Settings → Privacy & Security → Local Network and make sure Macropad is on.
  4. On Mac, if the firewall is enabled, allow incoming connections for Macropad Helper in System Settings → Network → Firewall → Options.
  5. Turn off VPNs on either device and try again.
The QR code won't scan

Allow camera access in Settings → Macropad → Camera. Turn up your Mac's screen brightness, hold the phone 20–40 cm away, and avoid glare. You can also make the QR window larger from the Helper menu.

It connects, but drops out or feels laggy

Macropad talks over your local network, so a weak Wi-Fi signal is the usual cause. Move closer to the router, prefer a 5 GHz network, and disable Low Power Mode on iPhone, which can pause background networking. If it persists, unpair and pair again from the Helper menu.

Can I control more than one Mac?

Yes. Pair each Mac once; you can then switch between them from the connection menu in the app. Each board can remember which Mac it's meant for.

Actions & permissions

Keys light up, but nothing happens on my Mac

macOS needs your permission before any app can send keystrokes. Open System Settings → Privacy & Security → Accessibility and turn on Macropad Helper. If it's already on, toggle it off and on again, then restart the Helper — macOS sometimes needs this after an update.

A shortcut works in one app but not another

Shortcuts are sent to whichever app is in front. Make sure the target app is focused, and that the shortcut is the same in that app — many apps let you customise their key bindings. For media and volume, use the dedicated Media actions instead of key presses; they work regardless of focus.

macOS asks to let Macropad “control” another app

That's the Automation permission, used by actions that talk directly to apps such as Music or Zoom. Click OK to allow it. You can review it later in System Settings → Privacy & Security → Automation.

How do I build a macro?

Select a component, choose Action → Macro, then add steps: key presses, typed text, delays, media or window commands. Steps run top to bottom. Use the play button in the editor to test it while connected.

Boards, sync & Pro

My boards don't appear on my other iPhone or iPad

Sync uses your iCloud account. On each device, make sure you're signed in to the same Apple Account, iCloud Drive is on, and sync is enabled in Macropad's settings. The first sync can take a few minutes on a slow connection.

What's included for free, and what does Pro add?
  • Free: up to 3 boards, every component type, and the Media, Windows and System packs.
  • Pro: unlimited boards and Pro packs such as Xcode and Zoom.
I bought Pro but it isn't unlocked

Go to Settings → Macropad Pro → Restore Purchases, making sure you're signed in with the same Apple Account you used to buy it. Purchases made with Family Sharing may take a moment to appear.

How do I cancel or get a refund?

Purchases are handled by Apple. To manage or cancel a subscription, open Settings → [your name] → Subscriptions. For refunds, use reportaproblem.apple.com — Apple doesn't allow developers to issue refunds directly.

Can I back up or share a board?

Yes. Open the board menu and choose Export to save it as a file you can keep or send to a friend. Import it from the same menu or by opening the file on iPhone.
